# akstOS: Операционная система для колледжа на Rust и ядре Linux

**akstOS** — специализированный легковесный дистрибутив для проведения лабораторных работ по операционным системам, системному программированию и архитектуре Linux в колледже.

Вся система инициализации (PID 1), командная оболочка, образовательные модули и утилиты написаны на **Rust**, а в качестве базового ядра выступает стандартный **Linux Kernel**.

---

## Архитектура системы

- **Ядро**: Linux Kernel (`vmlinuz`)
- **Процесс инициализации (PID 1)**: `/init` написан на Rust (модуль `sys::mount`, безопасное управление питанием `sys::power`).
- **Студенческая оболочка**: интерактивный цветной REPL (`shell::mod`), исключающий аварийное падение ядра при выходе.
- **Образовательный модуль колледжа**:
  - `lab list`, `lab info <N>`, `lab check <N>` — встроенная система выдачи и автопроверки лабораторных работ.
  - `sysinfo` (`neofetch`) — наглядный графический дашборд использования ОЗУ, ЦП и аптайма для обучения.
  - `bench` — бенчмарк для анализа быстродействия алгоритмов студентами.
  - `calc` — калькулятор математических выражений.
  - Базовые утилиты: `ls`, `cat`, `mkdir`, `rm`, `echo`, `ps`, `uname`, `reboot`, `poweroff`.

## Облачная сборка через GitHub Actions (Без использования места на ПК)

В репозиторий встроен workflow `.github/workflows/build.yml`. 
При каждом коммите в ветку `main`:
1. Виртуальная машина GitHub Actions собирает статический бинарник на Rust (`x86_64-unknown-linux-musl`).
2. Упаковывает файловую систему в загрузочный образ `initramfs.cpio.gz`.
3. Готовый загрузочный образ сохраняется в раздел **Artifacts** вашего репозитория.

---

## Локальная сборка и тестирование

### Вариант 1: Через скрипт сборки
```bash
./build.sh
```

### Вариант 2: Запуск в QEMU
```bash
qemu-system-x86_64 \
    -kernel /boot/vmlinuz \
    -initrd initramfs.cpio.gz \
    -append "console=ttyS0 quiet panic=1" \
    -m 256M \
    -nographic
```

## Структура репозитория

```
akstOS/
├── Cargo.toml                  # Конфигурация Rust и экстремальная оптимизация размера
├── Dockerfile                  # Контейнерная сборка
├── build.sh                    # Скрипт создания rootfs и initramfs
├── push_to_github.ps1          # Скрипт выгрузки в GitHub через REST API
├── .github/workflows/build.yml # CI/CD облачная сборка в GitHub
├── config/
│   └── os-release              # Идентификация дистрибутива akstOS
└── src/
    ├── main.rs                 # Точка входа PID 1 (akst-init)
    ├── sys/                    # Монтирование (/proc, /sys, /dev) и питание
    ├── college/                # Модули лабораторных работ и системного мониторинга
    └── shell/                  # Интерактивная командная оболочка студента
```
