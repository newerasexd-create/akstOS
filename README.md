# akstOS: Легковесная операционная система для старых компьютеров колледжа

**akstOS** — специальный дистрибутив на базе ядра Linux и системного пространства на **Rust**, созданный для запуска на очень старых и слабых ПК колледжа (Pentium 4, Celeron, AMD Athlon, от 128 МБ ОЗУ).

---

## Особенности сборки для старых ПК

1. **Экстремально низкие системные требования**:
   * **Процессор**: Любой x86 (32-бит или 64-бит) начиная с Pentium II/III/IV.
   * **Оперативная память (ОЗУ)**: от **64–128 МБ**.
   * **Размер всей системы в памяти**: всего ~4-8 МБ!
   * **Видеокарта**: любая древняя VGA / VESA (без 3D-ускорения, текстовый режим).
2. **100% Русский интерфейс**:
   * Все команды полностью русифицированы: `помощь`, `файлы`, `читать`, `папка`, `записать`, `память`, `тест`, `перезагрузка`, `выключить`.
   * Английские аналоги (`ls`, `cat`, `reboot`, `clear`) также сохранены для совместимости.
3. **Готовые лабораторные работы колледжа**:
   * Встроенная система заданий и автоматической проверки для студентов (`лаб список`, `лаб инфо`, `лаб проверить`).
4. **Двойная сборка в GitHub Actions**:
   * `akstOS-32bit-ancient-x86` — для 32-битных древних процессоров (Pentium 4, Celeron 32-bit).
   * `akstOS-64bit-modern-x86_64` — для 64-битных ПК.

---

## Как записать и запустить на старом ПК колледжа

### Способ 1: Загрузочная флешка (Ventoy или Syslinux)
1. Скачайте образ `akstOS-...cpio.gz` из раздела **Artifacts** последнего билда на GitHub.
2. Возьмите стандартное ядро Linux (например, `vmlinuz` от Debian/Alpine).
3. Строка параметров загрузки для древних ПК:
   ```text
   vmlinuz initrd=akstOS-32bit-ancient-x86.cpio.gz nomodeset vga=791 console=tty0 quiet
   ```
   *(Параметр `nomodeset` отключает современные видеодрайверы, чтобы экран не гас на старых материнских платах)*.

## Команды студента

| Команда на русском | Альтернатива | Что делает |
|---|---|---|
| `справка` | `help` | Список всех доступных действий |
| `лаб список` | `lab list` | Список лабораторных работ |
| `лаб инфо 1` | `lab info 1` | Задание к первой работе |
| `лаб проверить 1` | `lab check 1` | Автоматическая проверка сдачи |
| `создать_отчет 1` | - | Сформировать отчет студента |
| `память` | `sysinfo` | Монитор ОЗУ и процессора старого ПК |
| `тест` | `bench` | Замер скорости старого процессора |
| `файлы [папка]` | `ls` | Список файлов |
| `читать <файл>` | `cat` | Открыть текстовый файл |
| `папка <имя>` | `mkdir` | Создать каталог |
| `записать <файл> <текст>` | - | Быстрая запись текста |
| `удалить <файл>` | `rm` | Удалить файл |
| `процессы` | `ps` | Запущенные процессы |
| `очистить` | `clear` | Очистка экрана терминала |
| `перезагрузка` | `reboot` | Перезагрузка ПК |
| `выключить` | `poweroff` | Безопасное выключение питания |
