# akstOS: Легковесная операционная система для колледжа на Rust и Linux

**akstOS** — специализированный дистрибутив для проведения лабораторных работ и учебных занятий в колледже на базе ядра Linux и системного окружения на **Rust**.

Часовой пояс по умолчанию: **UTC+9**.

---

## Предустановленные программы колледжа

При установке akstOS на жесткий диск сразу развертывается полный комплект учебного ПО:

| Программа | Команда в терминале | Язык разработки | Описание |
|---|---|---|---|
| **WordCraft** | `ворд` (или `wordcraft`) | **Pure Rust** | Текстовый процессор (Word, DOCX, ODT, RTF) |
| **PdfCraft** | `пдф` (или `pdfcraft`) | **Pure Rust** | Просмотр, чтение и аннотирование PDF-документов |
| **GridCraft** | `таблицы` (или `gridcraft`) | **Pure Rust** | Электронные таблицы и анализ данных (Excel) |
| **DeckCraft** | `слайды` (или `deckcraft`) | **Pure Rust** | Создание и показ презентаций (PowerPoint) |
| **ArtCraft** | `рисование` (или `artcraft`) | **Pure Rust** | Растровый и векторный графический редактор |
| **Яндекс Браузер** | `браузер` | C++/Chromium | Веб-браузер для доступа к учебному порталу |
| **Python 3** | `питон` (или `python3`) | C/Python | Новейшая версия Python со стандартными библиотеками и pip |

Команда **`программы`** в терминале выводит статус и быстрый доступ ко всем приложениям.

## Установка на жесткий диск за 1 команду

1. Загрузите компьютер с флешки.
2. Введите команду:
   ```text
   установить
   ```
3. Выберите номер жесткого диска (например, `1`) и подтвердите (`да`).
4. Мастер автоматически создаст разметку MBR, отформатирует диск, установит ядро, настроит загрузчик **Syslinux MBR**, развернет офисный пакет на Rust, браузер и Python, а также создаст ярлыки на рабочем столе студента.
5. После перезагрузки компьютер сразу готов к учебным занятиям!
